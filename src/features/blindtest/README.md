# 匿名 A/B 盲听对照（blindtest）

在同一歌时对两支录音做匿名 X/Y 快切对照，解决「整体调低轻唱听不清、整体调高爆破音失真」的问题。

## 设计原则

- **只做分段恒定增益 + 60ms 线性过渡**，不做动态压缩/限幅，不抹平原唱重音。
- **证据不足就保留原声并写明原因**（片段过短、包络相似度不足、错位爆破音无对应瞬态）。
- **盲随机**：X/Y 与实际录音的映射在载入时随机生成，揭晓前界面不暴露来源。
- **原声随时可复听**：校准/原声模式在同一时间轴重建节点，raw 模式增益逐点恒为 1。

## 处理流水线

1. `lib/wav.ts` — 纯 WAV 解码（PCM16/24/32、FLOAT32，多声道下混）。
2. `lib/analysis.ts` — 25ms 帧 / 12.5ms 跳帧；最低 3% 分位估计本底；
   局部峰值突变（≥2.2 倍邻帧且高于本底 20dB）识别短爆破音；
   切出轻唱 / 可靠发声 / 爆破音 / 漏唱 / 首尾安静。
3. `lib/matching.ts` — 能量包络在 ±120ms 错位容差内做相关匹配；
   各自错位的爆破音、位置不同的漏唱不强行配对，写入 warning 并保留原声。
4. `lib/gain.ts` — 轻声补到校定的可听阈值（受峰值上限钳制）；爆破音只压不抬；
   匹配的可靠发声向几何中点对齐（±3dB 内）；`preserveAccents` 校验重音次序不被反转。
5. `lib/engine.ts` — Web Audio 双路 source 同时起播，快切仅 20ms 交叉淡变、不重启 source、不动播放头。
6. `lib/render.ts` — 同一自动化曲线的离线采样渲染，用于无浏览器环境验证实际输出。

## 验证

```sh
npm run fixture:blind   # 生成两支 10s 合成轻唱（各自错位爆破音 + 一段漏唱）到 public/media/blind-demo/
npm run test:blind      # 21 项 Node 测试：分析、匹配、增益、引擎快切/暂停/揭晓、样本级渲染
```

模拟时钟（`test/blindtest/mock-clock.ts`）把 Web Audio 调度落到虚拟时钟，
断言快切不创建新 source、暂停冻结播放头、raw 模式逐点增益为 1、来回切换同歌时可复现。

## 界面

右栏「匿名对照」标签页：支持上传 wav、选用当前练习句的本机录音、或一键载入示例对照；
证据时间线按片段类型着色，揭晓后展开每段增益数值与保留原声的原因。
